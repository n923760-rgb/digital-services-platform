## الهدف والنطاق

اختيار المالك في 2026-10-02: «لاحقًا، أكمل تجربة البوت». وكيل Office مؤجل؛ لا منفذ Word/Excel/PowerPoint جديد في هذا التغيير.
المرحلة الحالية تختبر الاتصال والأوامر والحالات المرفوضة دون شراء. لا يمكن إكمال تلخيص مدفوع مع تعطيل الدفع؛ تلك تجربة لاحقة لها سعر وشروط ودعم وصلاحية مستقلة.

## المطلوب

- جهاز أو VPS تجريبي عليه Git وDocker Compose V2.
- نسخة مستقلة من المستودع وبيانات PostgreSQL تجريبية، وبوت تجريبي مخصص.
- إعداد التوكن داخل ملف .env غير المتعقب على جهاز التشغيل؛ لا ترسله في الدردشة أو Git.
- عدم وجود عملية polling أخرى للتوكن نفسه.
- توفر المنافذ المحلية 8100 و8101 والشبكة الافتراضية 172.31.0.0/29. إن كانت مستخدمة، اختر إعدادات متوافقة قبل التشغيل وفق عقد المنتجات؛ اسم المشروع وحده لا يعزل منافذ المضيف أو الشبكات الثابتة.

## تشغيل معزول

نفّذ على بيئة التجربة فقط. إن كانت لديك نسخة بالفعل، استخدم مجلدًا منفصلًا. المرجع المثبت هنا يوفر نسخة معلومة، ويجب إعادة التحقق من أي مرشح أحدث قبل تجربته.

```bash
git clone https://github.com/n923760-rgb/digital-services-platform.git digital-services-platform-trial
cd digital-services-platform-trial
git checkout --detach 1d948707fa55d144d435dc971247c5c8c127a95f
cp .env.example .env
nano .env
```

استبدل كلمة مرور PostgreSQL وعدّل DATABASE_URL لتطابقها، وضع توكن البوت التجريبي. أبقِ:

```dotenv
TELEGRAM_ORDERS_ENABLED=false
TELEGRAM_STARS_ENABLED=false
SERVICE_ACTIVATION_ENABLED=false
```

استخدم اسم المشروع نفسه في كل أمر أدناه؛ هو يفصل قاعدة البيانات التجريبية عن volume المشروع الافتراضي. لا تنسخ بيانات العملاء أو بوت الإنتاج لهذه التجربة.

```bash
docker compose -p dsp-summary-trial up -d --build --wait db migrate api
curl --fail http://127.0.0.1:8100/api/health/ready
docker compose -p dsp-summary-trial --profile telegram up -d --build --wait telegram-bot
docker compose -p dsp-summary-trial --profile telegram ps
```

## فحص تيليجرام

افتح محادثة خاصة مع البوت التجريبي وسجل PASS/FAIL مع وقت التجربة:

| الحالة | النتيجة المتوقعة |
| --- | --- |
| /start ثم /services | رد واضح؛ لا منتجات قابلة للشراء عند بقائها معطلة |
| /summary | نفس مدخل قائمة الخدمات؛ لا ادعاء أن خدمة مدفوعة مفعلة |
| /orders | حالة طلبات هذا المستخدم أو حالة فارغة مفهومة |
| /cancel بلا عرض | رسالة عدم وجود عرض غير مدفوع |
| /terms و/paysupport قبل الإعداد | رسالة أن الشروط أو الدعم قيد التجهيز والدفع غير متاح |
| صورة أو تسجيل أو ملف | رسالة أن الخدمة الحالية تقبل النص فقط |
| أمر غير معروف | عرض الأوامر المتاحة |
| نص دون منتج مفعل | لا فاتورة ولا خصم؛ إرشاد بحسب حالة الخدمة |

لا تعرض هذه الجولة بوصفها إثباتًا لجودة التلخيص أو للدفع. لا يوجد وضع تلخيص مجاني مؤكد في هذا المصدر.

## لوحة الإدارة الاختيارية

لتجربة مسار الدخول والمنتجات فقط، اضبط ADMIN_COOKIE_SECURE=false لهذه البيئة المحلية عبر HTTP وحدها؛ في HTTPS يبقى true.

```bash
docker compose -p dsp-summary-trial --profile admin up -d --build --wait api web caddy
docker compose -p dsp-summary-trial exec -it api python -m platform_core.admin_bootstrap
```

اللوحة تستمع على loopback؛ على VPS اتصل عبر SSH tunnel محلي إلى 8101، ثم افتح http://127.0.0.1:8101/admin على جهازك. لا تفتح منفذ HTTP للعامة.
أنشئ منتجًا مسودة مربوطًا بالتلخيص المحلي، وعدل الاسم والوصف ثم أعد فتحه للتحقق من الحفظ. لا تختر سعرًا نيابة عن المالك ولا تفعّل المنتج في هذه الجولة. مع تعطيل التفعيل والدفع، غياب المسودة عن قائمة شراء العميل صحيح.

## التوقف والتشخيص

```bash
docker compose -p dsp-summary-trial --profile telegram stop telegram-bot
docker compose -p dsp-summary-trial --profile admin stop caddy web
docker compose -p dsp-summary-trial stop api db
```

لا تحذف volumes أو تغير إعدادات الإنتاج لمعالجة فشل تجربة. افحص السجلات محليًا، وشارك فقط نوع الخطأ بعد حذف التوكن وبيانات العميل. لا تنشر ملف .env أو مخرجات إعدادات البيئة.
فشل مصادقة البوت يجب أن يوقف دخوله قبل استرجاع الطلبات المالية؛ لا تختبر هذا على قاعدة تحتوي طلبات حقيقية.
